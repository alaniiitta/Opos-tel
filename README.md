# Opos TEL

App de estudio para las oposiciones de Técnico/a (Superior/Especialista) de Laboratorio.

- Tests de práctica con corrección y explicación
- Simulacros con tiempo y penalización
- 27 exámenes oficiales de 14 comunidades autónomas, con la respuesta de la plantilla publicada por cada tribunal
- Tarjetas de memoria, temario con apuntes y preguntas propias

Ábrela en **https://alaniiitta.github.io/Opos-tel/** y, en el iPhone, usa *Compartir → Añadir a pantalla de inicio* para instalarla como app. El progreso se guarda en el propio dispositivo.

Las preguntas oficiales proceden de los cuestionarios y plantillas publicados por los servicios de salud; cada examen indica su origen y si la plantilla es provisional.
